# Visual design system

- Primary: `#2563EB` (blue)
- Secondary: `#10B981` (green)
- Attention: `#F59E0B` (amber)
- Neutral: `#6B7280` (gray)
- Headings: Aptos Display / Inter; body: Aptos / Inter; code: Consolas / Fira Code
- Diagram notation: rounded rectangles = services/agents; cylinders = data stores; solid arrows = data flow; dashed arrows = control/approval flow.
- Keep diagrams legible, label trust boundaries, and distinguish implemented components from planned components.
